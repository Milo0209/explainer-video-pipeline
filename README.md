# explainer-video-pipeline

An automated pipeline for short vertical explainer videos: programmatic scenes rendered in React, local speech synthesis and recognition for word-synced captions, procedurally generated music and sound effects, and automated quality checks. Zero cloud costs.

## Highlights
- Fully local and deterministic renders
- QA gate before every export

Active – first reel shipped.
